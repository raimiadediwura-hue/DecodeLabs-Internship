# E-commerce Exploratory Data Analysis

## Project Overview
Exploratory Data Analysis of an e-commerce dataset containing 1,200 records and 14 columns.

## Tools Used
- Microsoft Excel
- Pivot Tables
- IQR Method

## Analysis Performed
- Descriptive statistics
- Product performance
- Order status analysis
- Payment method analysis
- Referral source analysis
- Monthly sales trend
- Outlier detection

## Key Findings
- Chair generated the highest product revenue.
- Credit Card generated the highest revenue among payment methods.
- Instagram had the highest customer count and referral revenue.
- June recorded the highest monthly sales.
- September recorded the lowest monthly sales.
- 8 potential outliers were identified using the IQR method.
