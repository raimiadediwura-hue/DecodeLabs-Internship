# Project 1: Data Cleaning and Preparation

## Project Overview

This project focused on cleaning and preparing an e-commerce sales dataset using Microsoft Excel and Power Query.

## Dataset

- 1,200 rows
- 14 columns

## Tools Used

- Microsoft Excel
- Power Query

## Data Cleaning Steps

- Standardized column headers
- Checked data types
- Checked for duplicates
- Handled missing values
- Replaced blank coupon codes with "NO COUPON"

## Skills Demonstrated

- Data Cleaning
- Power Query
- Microsoft Excel
- Data Preparation
