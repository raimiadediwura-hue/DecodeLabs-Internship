# Project 4: E-commerce Sales Dashboard (Data Visualization)

## Project Overview

This project focused on transforming e-commerce sales data into meaningful visualizations using an interactive dashboard.

Building on the data cleaning, exploratory data analysis, and SQL analysis completed in the previous projects, this project presents key performance indicators (KPIs), sales trends, product performance, payment analysis, order status, coupon code performance, and referral source analysis.

## Project Goal

The goal was to design an interactive dashboard to monitor sales performance, identify trends and patterns, compare business metrics, and support data-driven decision-making.

## Dataset

- Rows: 1,200
- Columns: 14
- Data Type: E-commerce sales data
- Period Covered: January 2023 – June 2025

## Tools Used

- Microsoft Power BI

## Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Total Units Sold

## Dashboard Features and Key Findings

### 1. Interactive Slicers

The dashboard includes slicers for:

- Year
- Product
- Coupon code
- Order Status
- Payment method

These slicers allow users to filter the dashboard and explore different aspects of sales performance.

### 2. Product Performance

A bar chart compares revenue across the seven products.

**Key Finding:**
Revenue was fairly evenly distributed across all seven products. Chair generated the highest revenue at approximately $196K, while Phone generated the lowest at approximately $152K. This suggests that no single product contributed disproportionately to overall revenue.

### 3. Customer and Time Analysis

A line chart displays monthly sales trends across the full date range.

**Key Finding:**
Revenue showed considerable month-to-month volatility, with no sustained upward or downward trend. The highest monthly revenue occurred in June 2024.

### 4. Payment Analysis

A bar chart compares revenue generated through different payment methods.

**Key Finding:**
Credit card payments generated the highest revenue, at approximately $263.85K, making credit cards the leading payment method by revenue.

### 5. Order Status Analysis

A pie chart displays the distribution of the 1,200 orders across different order statuses.

**Key Findings:**

- Cancelled: 250 orders (20.83%)
- Returned: 247 orders (20.58%)
- Delivered: 231 orders (19.25%)

These findings highlight the distribution of order outcomes and the importance of investigating cancellations and returns to identify potential operational improvements.

### 6. Coupon Code Analysis

compares revenue generated by different coupon codes.

**Key Finding:**
FREESHIP was the most frequently used coupon code and generated the highest coupon-related revenue, indicating that it was the strongest coupon code by usage and revenue in the dataset.

### 7. Referral Source Analysis

Two charts compare referral sources by revenue and number of orders or unique customers.

**Key Finding:**
Instagram generated the highest referral-source revenue and the highest number of customers, making it the leading referral source based on these measures.

## Business Questions Addressed

- Which products generate the highest revenue?
- How does revenue change from month to month?
- Which payment methods generate the most revenue?
- What is the distribution of orders by status?
- Which coupon codes are used most frequently and generate the most revenue?
- Which referral sources generate the most revenue?
- Which referral sources attract the most customers?

## Conclusion

This project demonstrated how data visualization can transform analyzed e-commerce data into an interactive dashboard for business performance monitoring.

The analysis showed that revenue was relatively evenly distributed across products, monthly sales fluctuated over time, credit cards generated the highest payment-method revenue, FREESHIP led coupon performance, and Instagram was the strongest referral source by revenue and order volume.

The dashboard brings these findings together through KPI cards, charts, and interactive slicers, making it easier to explore sales performance and identify areas for further investigation.

This project completes the progression from data cleaning and exploratory data analysis to SQL querying and visual reporting.
